等级成长

规则说明（里程碑制）
里程碑制：到达该等级即生效，并持续到被更高的行覆盖，不必每级都填。
例：2级填 10% → 2、3级都是 +10%；4级填 20% → 从4级起 +20%（2级那行才失效）。
公式：属性 = 基础 ×(1 + 当前生效档位加成)

🔋 自定义条 · 联动设置

名字、数值、颜色在角色卡里直接改；这里配置战斗联动。可以填负数——条越高伤害越低、或每回合倒扣，都是合法的惩罚机制。
护盾条可以当额外血量用：状态技能给它加值就是「套盾」，伤害先扣盾再扣 HP。默认不允许负值，避免把条透支成负数去放大招。
次数护盾：条值就是剩余层数，任何伤害都按「一层挡一击」处理（比如 3 层 = 要打 3 下才破）。减伤只在护盾条有值时生效，先减伤再扣盾。
例：填 20 时，条 50% → +10% 伤害，条满 → +20%；再填「满值额外 10」时满值共 +30%。填负数就是越满越虚。
