# 世界、席位与共同决定

[← 项目首页](../README.md) · [试跑指南](QUICK_START.md)

世界建立时固定 `gm`（真人 GM）、`ai`（AI 主持）或 `co-create`（自由共创）。房主身份独立于普通玩家席位，房主也可领取一个主角；没有主角的房主仍能管理房间、审批与裁定平票。

## 初创世界的治理

| 初创设置 | 决策方式 | 授权 |
| --- | --- | --- |
| 民主 | 有效赞成票严格多于反对票，平票交给房主；无人有效投票则拒绝 | 无成员转授权 |
| 民主 + 房主否决 | 多数通过并且房主显式批准；房主可否决 | 无成员转授权 |
| 独裁 | 房主决定；可把指定审核或管理事项授予成员 | 房主随时授予 / 收回，受权人不能转授权 |

选民名单在开票时冻结，由当时拥有已注册主角的成员组成。之后归还角色或新注册，不改变已经开放的这张选票。NPC、怪物和随从不增加票数。

截止前，完整选民名单的绝对多数可提前定案。截止时未投票者使用其保存的赞成 / 反对 / 弃权偏好，默认弃权；自动票保留来源。弃权不进入最终有效票分母。一票赞成、五票弃权可通过；全部弃权不通过。

提案审核权按地图、规则、生物、故事分别授予；角色管理、成员注册、图鉴解锁、回合推进也是独立权限。受权人不会因一项授权获得房主身份。治理方式不通过普通规则提案修改。

## 统一回合

自由共创的意图先规划并预留额度，结束后进入统一结算。服务器以日志可查的随机公平顺序处理同一波行动，保留同一角色行动的先后依赖。当前在线参与者未结束时不结算；已结束成员可在结算前撤回。

共享资源冲突可配置随机胜出、全部失败并退款，或比较指定属性 / 等级；相同结果用服务器随机决胜。先取得材料再制作的连续行动按库存实际变化执行，失败不能凭空生成物品。

世界改动在下一回合开始时采用。新 NPC 获得实际 ID，行为脚本再绑定该 ID；NPC 可待机、巡逻、敌对、交易或响应指定事件，不执行任意代码。交易使用 NPC 的真实库存。

## 行动力

行动力余额、最大余额、每回合允许支出的额度分别计算。上限最多 100，金额最多六位小数。增加上限不会自动补满；降低上限裁剪当前余额。

- **每小时恢复**：以房主服务器时间计算完整小时，玩家离线、服务器关机经过的时间也纳入，下次处理时恢复至上限；满额不额外储存额度。
- **每回合恢复**：新回合开始时只恢复当前在线已注册玩家及其受控随从。自动 NPC 独立恢复，不依赖房主是否在线。

两种恢复方式互斥，可通过当前模式的规则修改途径后续调整。NPC 和玩家使用同一资源机制。未配置的费用不会猜测；只禁止依赖它的操作，并说明原因。

## 自由数值与成长

自由卡使用手动生命、熟练、AC 与速度，基础属性允许自定数值，不强制 5e 背景加点。具体技能明确配置攻击来源、近战 / 远程、攻击检定 / 豁免、十三种伤害类型、伤害骰及加值属性，不统一叠加力量。

成长可使用全局经验或钓鱼、种田、战斗等独立经验轨道。世界规则定义各级经验需求、奖励点数、升级费用、增量和最终基础上限。装备临时加成不占基础升级上限。

修改经验曲线保留历史总经验、等级与已赚 / 已花点数，当前等级内进度按比例换算。修改上限、成长或装备不会顺带回满生命或资源。

标准 SRD 卡保留标准建卡与升级校验。复制为自由卡使用新 ID 并保留来源指纹，法术位和原生技能引用保持原义；无法等价的职业与跨角色效果列在报告中，原卡不变。

## 隐私与纠正

服务器仅发送本人完整卡、可见地图棋子、已解锁图鉴和其他成员主动公开的分组。隐藏单位、GM 私密效果、私密笔记和他人草稿不会靠前端隐藏来保护。

AI 初始化或决策是一份待采用的建议：先校验、显示预览、再由房主确认。AI 不能改变房主、成员、投票或授权。程序骰和 AI 骰分别校验并保存来源与实际骰面，缺少骰面时等待补充，不自动换骰源。

管理调整、审批、投票与结算保存审计事件。撤销有顺序限制，任意历史操作及所有后续依赖的精准回滚仍有边界；见[备份与恢复](BACKUP.md)。
