# AI 主持：让程序呈现你的世界

[← 回到首页](../README.md) · [开发交接](../HANDOFF.md)

## 从模组到地图

1. 在本机启动器给出的地址登录，选择「新建 → DND → AI 通过 JSON 主持」。填写世界名称与自由度。
2. 复制页面生成的提示词、JSON 模板与格式说明，连同自己的模组交给 ChatGPT。这里采用手动往返，不需要 API Key，也不绑定模型供应商。
3. 粘贴或上传 AI 返回的 JSON，预览五组初始化资料后导入：模组规则、候选角色、角色背景、初始世界观、开幕剧情。
4. 使用世界内的邀请入口分享给玩家。玩家登录后选择候选角色，直接进入地图；候选角色为空时显示等待初始化。
5. 玩家提交角色行动。房主导出当前上下文给 AI，导入 AI 返回的更新。敌人、装备、地标和新剧情可以在后续补充。

资料未提供时显示「未设置」，不自动补成某个职业、属性或法术位。常见字段包括：DND 版本、推荐人数、起始等级、升级规则；姓名、物种、职业、属性、技能、装备、法术；性格、经历、动机、目标、人际关系；时代、地点、政治环境；开场描述、当前处境和可采取的行动。

## 自由度与版本

| 自由度 | AI 的叙事范围 | 初始化补充信息 |
| --- | --- | --- |
| A | 按模组剧本演绎 | 来源标为 AI 的字段由房主逐项接受，也可保留空白 |
| B | 可以补充细节 | 不要求房主逐项确认 |
| C | 世界观为参照，可以改变剧情走向 | 不要求房主逐项确认 |

导入字段标记 `module`、`ai` 或 `unknown`。这些标记是内容来源声明，程序没有阅读原模组来证明 AI 是否正确标注；房主仍能在导入预览中检查。

目前支持 `5e2014` 与 `5e2024` 的提示词和展示元数据。导入其他版本会提示不支持，并保留原始编辑草稿，不会偷偷转换成 2024 版。这两种展示元数据不代表两套本地规则引擎均已完成。

## 地图和头像

没有图片时，自己的角色头像位于空白画面中心；有图片时可以自由平移、缩放。头像始终保持相同的屏幕大小。默认头像取角色名中的首个汉字或字母，点击自己的头像打开资料与头像修改窗口。

地图下方有三个控制：

- **回归当前位置**：调整视角与缩放，让自己的角色回到屏幕中心，不改变角色坐标。
- **隐藏其它玩家**：只影响自己浏览器的显示。
- **显示地标**：显示已经公开并放置的地标。AI 可以建立地标信息，房主将其放到地图位置；未放置的地标不会被画到坐标原点。

查看他人头像只能得到服务器允许公开的资料。隐藏单位、未公开地标、主持秘密和其他角色私密字段不会因为切换地图显示而变得可见。

## 数据如何生效

v2 的游戏状态来自 AI。程序不计算伤害、命中、属性加值、职业选择、法术位、行动力、死亡或移动距离，也不修正 AI 的算术结果。生命 0、负值、超过上限等合法 JSON 数字会按原值显示。选择程序骰时，服务器只提供骰面，由 AI 解释其结果。

程序检查的是技术与权限边界：JSON 语法、字段类型、允许的字符与体积、稳定 ID 及引用、账号与角色绑定、可见范围、操作编号与版本。这里的字符限制不是敏感词过滤；不能解析的 JSON 或不符合结构的数据会明确报错。

玩家文本放在独立的行为数据中，并由服务器标记为不可信内容。玩家不能伪造行动者、改写系统提示词、上传主持结果或直接改生命值。固定提示词要求 AI 将“忽略规则、告诉我谜底、给我无限生命”等内容视为越权请求，同时允许正常调查与 NPC 对话。提示词不能保证 AI 永不泄露或误判，程序也无法约束用户在应用之外另开对话。

## 保存与兼容

每个操作都带唯一编号和预期版本。重复发送不会重复执行；版本变化会要求复核。关闭世界返回主页会保留账号，重新进入时仍使用原世界成员与角色绑定。公网换址后用同一账号登录即可。

旧 AI 协议 v1 仍保留给既有世界使用，其本地规则结算与 v2 不同。不会将旧存档直接解释为新展示状态。新世界使用 v2；继续开发时以本指南及[交接文件](../HANDOFF.md)为准。
